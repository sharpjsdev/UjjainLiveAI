PROBLEM FIXED:
--------------
When users paused during voice input and continued speaking, earlier text
was being lost/replaced instead of accumulated.

Example:
  User says: "Where is the temple"
  User pauses: 2 seconds
  User continues: "from here"
  
  BEFORE (BROKEN): ❌ Only "from here" sent to AI
  AFTER (FIXED):   ✅ "Where is the temple from here" sent to AI


HOW IT WAS FIXED:
-----------------
Added smart word extraction that detects when the speech library corrects
itself after a pause and extracts ONLY the new words to append.

Key Logic:
  if (newText.startsWith(oldText)) {
    newWords = newText.substring(oldText.length)  // Extract only new
  }
  accumulatedText += newWords  // Append only new words, not duplicates
